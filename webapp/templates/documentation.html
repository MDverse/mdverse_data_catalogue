Data Annotation Pipeline

MDverse relies on MetaMD to extract essential Molecular Dynamics parameters directly from dataset descriptions and materials and methods sections of publications.

MDverse Tools & Services

REST API

Open Tool

Provides programmatic OpenAPI access to datasets, files, publications, and AI models in JSON format.

MetaMD

Source Code Open Tool

An interactive tool designed to annotate dataset descriptions and scientific texts to extract essential Molecular Dynamics (MD) parameters required for simulation reproducibility. It also allows researchers to assess metadata completeness and ensure all key simulation details are present before repository submission.

Paper2Repo

Open Tool

Converts scientific preprints (PDF or DOI) into standardized dataset titles, descriptions, and metadata drafts formatted for submission to public repositories (Zenodo, Figshare, NOMAD, etc.).
